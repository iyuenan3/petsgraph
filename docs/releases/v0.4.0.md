# PetsGraph v0.4.0

这一版让李五百更适合长时间安静待在桌面上。十种睡姿、点击坐起、再次点击回去睡觉、随机换姿、指定睡姿和枕头场景保持不变，主要升级集中在 CPU、内存和长期运行稳定性。

## 下载与安装

推荐下载 `PetsGraph-v0.4.0-macOS-arm64.dmg`：

1. 打开 DMG。
2. 把 `PetsGraph.app` 拖入 `Applications`。
3. 第一次启动时，如果 macOS 阻止打开，请在 Finder 中右键 App 并选择「打开」。也可以前往「系统设置 > 隐私与安全性」确认打开。

本版本只支持 Apple 芯片 Mac，需要 macOS 14 或更高版本。当前 App 使用 ad-hoc 签名，没有 Developer ID 签名和 Apple 公证，因此首次打开会出现上述安全提示。

## 改进

- **更适合长期陪伴**：本机普通睡眠约占 1.3% 到 1.6% CPU，物理内存占用约 53 MiB；连续换姿约占 2.1% 到 2.7% CPU，物理内存占用约 19 到 46 MiB。不同设备和系统版本的结果会有差异。
- **画面质量保持不变**：v0.4.0 从 v0.3.1 已批准的透明 PNG 确定性编译低功耗副本，没有重新生成、补帧、逐帧定位、光流、骨骼或交叉淡化。
- **减少重复启动**：同一用户再次启动当前版本时，新进程会在加载素材前退出，避免同时出现两只宠物并重复消耗 CPU 和内存。
- **更严格的包校验**：运行时会检查低功耗媒体的路径、字节数、SHA-256、帧数、裁剪坐标和隐藏文件异常，损坏的素材包不会静默进入桌面播放。

## 素材与体积

本版本继续内置 53 个动作片段、6,866 帧和约 286 秒动画，包括 7 种普通睡姿、3 种枕头睡姿和完整有向过渡。

获批 PNG 继续作为制作事实源保留。公开 App 内嵌约 1.827 GB 的固定裁剪预乘 RGBA 运行时副本，用磁盘空间换取更低的持续 CPU 和内存开销。无损压缩后的 DMG 约 548 MiB，备用 App ZIP 约 537 MiB。

## 发布附件

- DMG：普通用户推荐安装入口。
- App ZIP：不使用 DMG 时的备用下载。
- 睡姿总览：展示当前内置李五百的 10 种睡姿。
- `SHA256SUMS.txt`：上述三个附件的完整性校验值。
