# PetsGraph v0.5.10：五百与飞流

这是 PetsGraph 的首个双宠公开版本。一个 App 进程同时内置五百和飞流，两只宠物各自睡觉、换姿、响应点击和保存位置，不会同步翻身。

## 新增

- 首次安装默认在屏幕左下角横排显示五百和飞流。
- 菜单可以分别装载、卸载宠物，并为每只宠物指定中文睡姿。
- 两只宠物拥有独立随机时钟、动作状态、拖动位置和动作图。
- 全局大小提供 `0.5×`、`0.75×`、`1.0×`、`1.25×`、`1.5×`、`1.75×` 和 `2.0×` 七档。
- 飞流加入 5 种无道具睡姿、4 种猫窝睡姿和两个场景坐姿，视觉基准比五百大 5%。

## 修复与体验

- 桌面窗口改为 clip 级固定正方形视口，减少安全画布造成的透明留白和过宽提示框。
- 屏幕边界只约束当帧可见内容，宽过渡不再因为透明视口产生额外跳动。
- 飞流进入猫窝时使用已经人工通过的固定展示位移，不重新生成或逐帧定位素材。
- 修复飞流猫窝右侧过度抠图，只恢复缺失猫窝像素，不改变飞流主体或动作几何。
- 菜单中的宠物名称统一使用“五百”和“飞流”，不带姓氏。

## 验证

- 67 项 XCTest，0 失败。
- 两个宠物包共 84 个 clip、12,013 帧，结构、完整性和运行时媒体校验通过。
- App 主程序为 Apple 芯片 `arm64`，最低支持 macOS 14。
- App 与两个宠物包均为 `0.5.10`，两个包均为 `runtime-chain-approved`、`installable=true`。
- ad-hoc 签名和 DMG 校验通过。

## 安装

Release 只提供 `PetsGraph-v0.5.10-macOS-arm64.dmg`，不再提供 ZIP 或独立宠物包。

打开 DMG，把 `PetsGraph.app` 拖入 Applications。当前版本尚未使用 Developer ID 签名或 Apple 公证，首次打开时请在 Finder 中右键 App，选择「打开」并确认。
