# PetsGraph v0.6.0：Windows 11 x64 与 Apple 芯片 macOS

PetsGraph v0.6.0 同时提供 Windows 11 x64 便携 ZIP 和 Apple 芯片 macOS DMG。两个版本都内置五百和飞流，并使用已经验收的双猫相伴 Logo。

## 下载

- Windows 11 x64：`PetsGraph-v0.6.0-Windows-x64.zip`
- Apple 芯片 macOS 14 及以上：`PetsGraph-v0.6.0-macOS-arm64.dmg`

两个桌面宿主都继续内嵌已批准的五百与飞流 `0.5.10` 宠物包。应用版本与宠物内容版本分别记录，品牌更新不会改写或伪造已经验收的 12,013 帧媒体版本。

## Windows 新增

- 新增 Windows 11 x64 原生透明置顶窗口、逐像素鼠标穿透、拖动和系统托盘菜单。
- 五百与飞流继续使用各自独立的随机时钟、动作状态、位置和中文睡姿。
- 支持分别显示或隐藏宠物、指定睡姿，以及 `0.5×` 到 `2.0×` 七档全局大小。
- 采用 .NET 10 WPF self-contained 便携包，不需要预装 .NET。

完整解压 ZIP 后运行 `PetsGraph.exe`。不要只复制主程序，`PetsGraph.exe`、.NET 运行文件和 `Pets` 文件夹必须保持在同一目录。

Windows 版本没有代码签名，可能显示 SmartScreen 提示。请只从本项目 GitHub Release 下载。

## macOS 更新

- App 与 DMG 更新到 v0.6.0，并使用新的双猫相伴 Logo。
- 继续支持 Apple 芯片与 macOS 14 及以上版本。
- 保持 ad-hoc 签名，不使用 Developer ID 签名或 Apple 公证。
- 五百、飞流、动作图和逐帧媒体内容保持为已经验收的 `0.5.10` 宠物包。

打开 DMG 后，把 `PetsGraph.app` 拖入 `Applications`。首次启动如果被系统阻止，请在 Finder 中右键 App 选择「打开」，或前往「系统设置 > 隐私与安全性」确认打开。
