# PetsGraph v0.6.0：Windows 11 x64 便携版

这是 PetsGraph 首个 Windows 版本，只面向 Windows 11 x64。它内置五百和飞流，复用 macOS 版本已经批准的双宠动作包，并使用原生 .NET 10 WPF 桌面窗口。

## 新增

- 新增 Windows 11 x64 原生透明置顶窗口、逐像素鼠标穿透、拖动和系统托盘菜单。
- 五百与飞流继续使用各自独立的随机时钟、动作状态、位置和中文睡姿。
- 支持分别显示或隐藏宠物、指定睡姿，以及 `0.5×` 到 `2.0×` 七档全局大小。
- 采用用户确认的双猫图标，Windows 与 macOS 共用同一品牌视觉。

## 交付方式

Release 只提供 `PetsGraph-v0.6.0-Windows-x64.zip`。这是 self-contained 便携包，不需要预装 .NET，不提供 MSIX、安装器或代码签名。

完整解压 ZIP 后运行 `PetsGraph.exe`。不要只复制主程序，`PetsGraph.exe`、.NET 运行文件和 `Pets` 文件夹必须保持在同一目录。
