# 李五百睡觉陪伴 v0.3.0

这是 petsgraph 的第一个公开版本。它只做安静陪伴：五百大部分时间在桌面上睡觉，偶尔自然换睡姿；点击五百会让它醒来坐好，再次点击会让它回去睡觉。

## 下载与安装

推荐下载 `PetsGraph-Wubai-Quiet-Companion-v0.3.0-macOS.dmg`：

1. 打开 DMG。
2. 把「李五百睡觉陪伴」拖入「应用程序」。
3. 第一次启动时，如果 macOS 阻止打开，请在 Finder 中右键 App 并选择「打开」。也可以前往「系统设置 > 隐私与安全性」确认打开。

本版本只支持 Apple 芯片 Mac，需要 macOS 14 或更高版本。当前 App 使用 ad-hoc 签名，没有 Developer ID 签名和 Apple 公证，因此首次打开会出现上述安全提示。

## 这个版本有什么

- 菜单栏新增「选择睡姿」，可直接选择 10 种睡姿。
- 所有面向用户的姿态和状态都使用中文，不显示内部动作 ID。
- 普通睡姿：趴卧、左侧蜷卧、左侧伸展、仰卧、蜷缩仰卧、松散半仰卧、睡眠香箱。
- 枕头睡姿：头趴枕头、紧凑半仰卧、整身蜷睡。
- 指定睡姿继续使用完整动作图。正在播放不可中断过渡时，新选择会排队，不会硬切画面。
- 启动后默认位于屏幕左下角，支持全桌面拖动，并保持在普通窗口和 Dock 前方。
- 运行时完全离线，不上传照片，不连接素材生成服务，也不收集遥测数据。

## 发布附件

- DMG：给普通用户安装。
- App ZIP：无需 DMG 的备用下载。
- `.petsgraph-pet` ZIP：供开发者检查或复用素材包契约。
- 睡姿总览图：展示本版本的 10 种睡姿。
- `SHA256SUMS.txt`：附件完整性校验值。

正式包包含 53 个逐帧动作片段、14 个姿态节点、39 条有向边和 6,925 条完整性记录。v0.3.0 复用已经通过人工验收的 v0.2.0 素材帧，只增加中文显示名、指定睡姿交互和公开发布包装，没有重新生成、抠图或改写获批帧。
