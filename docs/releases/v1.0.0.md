# PetsGraph v1.0.0：零素材多宠 Player

PetsGraph v1.0.0 是 PetPack 1.0 新架构的首个正式播放器版本。Player 免费开源、离线运行，安装包不包含五百、飞流或任何客户宠物素材。用户单独获得 `.petpack` 后装载，Player 保存内部副本，原始文件由用户自行长期保存。

## 下载

- Apple Silicon macOS 14 及以上：`PetsGraph-v1.0.0-macOS-arm64.dmg`
- Windows 11 x64：`PetsGraph-v1.0.0-Windows-x64.zip`

Release 只包含以上两个附件，不提供 App ZIP、安装器、独立宠物包、预览图或校验和附件。精确字节数与 SHA-256 固定在 `release/manifests/v1.0.0.json`。

## 主要能力

- 同时装载零只、一只或多只 PetPack 1.0 宠物。
- 每只宠物拥有独立动作图、独立随机时钟、固定位置和包级基础体型。
- 支持拖动、按单只或全部显示与隐藏、按单只或全部卸载。
- 全部宠物共享 `0.5×`、`0.75×`、`1.0×`、`1.25×`、`1.5×`、`1.75×`、`2.0×` 七档大小。
- 已显示的宠物在“显示宠物”中置灰，已隐藏的宠物在“隐藏宠物”中置灰。
- macOS 可从状态栏装载，也可在访达中直接双击 `.petpack`。
- “关于 PetsGraph”显示当前应用版本，并说明 Player 与独立宠物内容的边界。
- 不提供点击动作、睡姿选择、窗口随步行移动、声音、账号、遥测或在线授权。

## macOS 安装

1. 打开 DMG，把 `PetsGraph.app` 拖入“应用程序”。
2. 当前 App 使用 ad-hoc 签名，尚未使用 Developer ID 或 Apple 公证。
3. 首次启动如果被阻止，在 Finder 中右键 App 选择“打开”。如果系统仍然阻止，前往“系统设置 > 隐私与安全性”，点击“仍要打开”，完成认证后在第二个确认窗口再次点击“仍要打开”。
4. 从状态栏菜单选择“装载宠物包…”，或者在访达中双击 `.petpack`。

## Windows 安装

1. 完整解压 ZIP，不要只取出 `PetsGraph.exe`。
2. 双击 `PetsGraph.exe`，从系统托盘菜单选择“装载宠物包…”。
3. 当前 ZIP 没有代码签名，Windows 可能显示 SmartScreen。只在确认下载来源与清单摘要后继续。
4. 不要删除或移动解压目录中的其他运行文件。Player 是 self-contained 构建，不要求另外安装 .NET。

## 数据与升级

- macOS 数据根：`~/Library/Application Support/PetsGraph/`
- Windows 数据根：`%LOCALAPPDATA%\PetsGraph\`
- `Library` 或 `library` 保存 Player 管理的 canonical PetPack，`Cache` 或 `cache` 可以重建。
- 升级 Player 只替换应用程序，不会删除已装载宠物、位置、全局大小和显示状态。
- 隐藏只停止显示并保留内部宠物包。卸载会删除内部包、缓存、位置和显示状态，再次使用需要原始 `.petpack`。

## 验证与已知边界

- PetPack 参考验证器 33 项、Codex 宠物 3 项、Swift 33 项和 Windows MSTest 45 项通过。
- macOS build 18 已完成双宠正常速度、独立换姿、拖动、四边贴靠、大小、重启、菜单、透明命中和长期运行人工验收。正式 `1.0.0` build 19 只改变版本与发布包装，不改变已验收的播放路径。
- 两只宠物同时显示的 60 秒稳定态样本中，CPU 平均约 `0.74%`、常态 `0.6%`、峰值 `2.0%`；物理内存为 `64.7 MB`、峰值 `67.4 MB`。这是当前动作组合的短时样本，不代表所有转场的上限。
- Windows x64 已完成 45 项测试、零警告 WPF 构建、self-contained 打包、AMD64 PE、零素材边界和原生 PetPack 校验。本轮没有新增真实 Windows GUI 人工复验，不能把 Windows Runner 结果写成透明窗口、DPI、拖动、托盘、多显示器或长时间视觉验收。
- 两个平台都未进行商业代码签名。macOS 会出现 Gatekeeper 提示，Windows 可能出现 SmartScreen 提示。

历史 `v0.6.0` 继续保留为内嵌五百和飞流的旧架构回滚版本，不会被覆盖或移动标签。
