# PetsGraph v0.3.1

这是通用品牌名称启用后的第一个版本。App 现在统一叫做 `PetsGraph`，当前内置宠物是李五百。以后增加其他宠物时，运行时名称保持不变，宠物身份和行为由宠物包决定。

## 下载与安装

推荐下载 `PetsGraph-v0.3.1-macOS-arm64.dmg`：

1. 打开 DMG。
2. 把 `PetsGraph.app` 拖入 `Applications`。
3. 第一次启动时，如果 macOS 阻止打开，请在 Finder 中右键 App 并选择「打开」。也可以前往「系统设置 > 隐私与安全性」确认打开。

本版本只支持 Apple 芯片 Mac，需要 macOS 14 或更高版本。当前 App 使用 ad-hoc 签名，没有 Developer ID 签名和 Apple 公证，因此首次打开会出现上述安全提示。

## 相比 v0.3.0 的变化

- App、DMG 和 Bundle 名称统一为 `PetsGraph`。
- Bundle ID 从五百睡眠专用标识收敛为 `com.maxwell.petsgraph`。
- 菜单顶部显示「当前宠物：李五百」，以后可以直接显示其他宠物包的名称。
- 操作反馈从宠物包读取名字，不再把“五百”写死在通用运行时代码中。
- Release 不再上传独立 `.petsgraph-pet`。素材包已经内嵌在 App 中，普通用户只需要 DMG。
- 发布工作流会拒绝独立素材包附件，并验证草稿中的附件集合与清单完全一致。

## 素材与体积

本版本继续使用已经通过人工验收的 53 个逐帧动作片段，共 6,866 个运行时帧和约 286 秒动画。全部获批帧与 v0.3.0 的 SHA-256 完全一致，没有重新生成、抠图或改写。

安装包较大的主要原因是 App 内嵌约 465 MB 的逐帧透明 PNG。PNG 已经压缩，再套 ZIP 或 DMG 只能小幅缩减。后续会在保留 PNG 制作事实源的前提下，单独验证更小的运行时编译格式，不会为了减包未经视觉验收就降低毛发、透明边缘或动作质量。

## 发布附件

- DMG：普通用户推荐安装入口。
- App ZIP：不使用 DMG 时的备用下载。
- 睡姿总览：展示当前内置李五百的 10 种睡姿。
- `SHA256SUMS.txt`：上述三个附件的完整性校验值。
