# ARCHITECTURE：petsgraph

> 宠物包精确字段见 `SPEC.md`，产品目标见 `PRD.md`，决策理由见 `DECISIONS.md`。

## 目标产品数据流

```text
已批准宠物素材与动作图
  → 包编译器固定变换、哈希与图校验
  → 本地 .petsgraph-pet
  → 离线包加载器
  → 睡眠行为调度器
  → 安全退出与路径规划
  → 下一条边和目标循环预加载
  → 逐帧渲染器
  → AppKit 透明置顶窗口
  → 宠物本体点击与全桌面拖动
```

素材制作侧与运行时通过数据包隔离：

```text
用户照片
  → 用户自行配置的 Seedance 等 provider
  → 连续视频母片
  → 抠图、固定画布归一化与机械预筛
  → 单动作、图边和完整路径人工验收
  → 批准配方与 PNG 事实源
  → 包编译器
```

## 目标与当前实现

| 表面 | 睡眠 MVP 目标 | 当前工程原型 | 差距 |
|---|---|---|---|
| 默认行为 | 启动即睡、随机长尾换姿 | 已有睡眠调度实验，也保留走跑行为实验 | 删除首发模式的目的地移动与强制走跑入口 |
| 点击 | 只点击宠物，在睡眠与场景坐姿间切换 | 工程预览仍可监听桌面目的地点击 | MVP 不安装全局桌面点击 monitor |
| 拖动 | 宠物本体可拖到全桌面任意位置 | 已有逐帧 alpha 命中与 x/y 手动偏移实验 | 枕头场景需要区分猫体与道具命中区 |
| 窗口层级 | 位于普通窗口和 Dock 前方，不抢键盘焦点 | AppKit `NSPanel` 已使用高窗口层级并加入所有 Space | 仍需完成全屏、锁屏与长时间人工验收 |
| 普通睡眠 | 多姿势随机切换，root motion 为零 | 趴卧与左侧蜷卧闭环已通过桌面验收，其他素材逐步接入 | 选择首发节点并补点击醒来路径 |
| 枕头睡眠 | 场景粘性、道具连续、独立坐姿 | 已有批准入口、通过目标姿势和部分母片 | 缺网关循环、正式分段、下枕回程与 `sit.front.pillow` |
| 安装 | 严格校验后本地安装，可回滚 | 只能从显式路径运行工程预览包 | 缺安装入口和首个 `installable=true` 包 |

当前工作树中的点击目的地移动、左右镜像工程验证和强制走跑菜单只属于历史能力验证。它们不能被 README、MVP 包或默认启动参数包装成首发产品能力。

## 1. 宠物包与包加载器

`PetsGraphCore` 负责：

- 安全解析 `package.json`、`graph.json`、clip 清单、帧引用和完整性清单。
- 从动作图显式推导必需片段，不依赖目录枚举。
- 拒绝缺失、篡改、符号链接、越界路径和带 hidden 标记的必需文件。
- 验证节点、边、入口出口姿态、安全退出帧、预加载引用和逐帧 root motion。
- 按单调时间直接采样累计 root motion，掉帧后不累加历史 delta。

包加载成功只证明结构和完整性满足契约，不代表素材已经人工通过，也不代表包可以安装。

## 2. 动作图与节点职责

节点除姿态与朝向外，还必须表达产品职责：

- `dwell`：允许自主调度，必须有可无限停留循环。
- `gateway`：连接场景或汇合路径，只短暂停留，不参与随机抽选。
- `interaction`：点击后的坐姿等明确响应，不参与自主随机。
- `cyclic`：走路或跑步等未来可选活动循环，不属于睡眠 MVP 默认图。

节点还声明 `scene`。首个 MVP 至少支持 `floor` 与 `pillow`。行为层不能把不同场景的节点当成视觉等价节点，尤其不能从枕头睡姿硬切到没有枕头的坐姿。

普通路径：

```text
stable/current-loop
  → waiting-for-safe-exit
  → preload-edge-and-target
  → playing-directed-edge
  → entering-target
  → stable/target-loop
```

过渡开始后，普通自主请求不能中途改变目标。点击可以替换尚未开始的普通目标，但不能截断已经播放的批准边。

## 3. 睡眠行为调度器

行为层只产生意图，不直接选择 clip：

- 默认意图为 `sleep`。
- 在当前 `dwell` 节点停留一段随机时间。
- 从允许的相邻睡姿中选择近期未出现的目标，并让图规划器生成完整路径。
- 枕头场景使用独立的进入概率、最小停留和退出冷却，避免道具频繁出现与消失。
- `gateway`、`interaction` 和不可中断过渡不进入自主候选集。
- 同一时间最多保留一个尚未开始的用户目标，后到点击可以替换旧目标，不能形成无限队列。

具体时间分布属于宠物行为配置，必须通过真实时间观察验收，不写死在视频片段或帧时长中。

## 4. 点击、拖动与窗口层级

MVP 只处理两类直接操控：

1. 点击宠物本体，在睡眠与当前场景坐姿之间切换。
2. 按住宠物本体拖动透明原生窗口。

目标运行时不监听宠物之外的桌面点击，也不需要辅助功能权限。命中测试必须使用逐帧宠物区域，不能把透明画布或枕头的 alpha 误当成宠物身体。

拖动立即暂停普通行为，清除尚未开始的目标。松手后保留用户设置的 x 和 y，并从兼容稳定姿态恢复。后续任何自主 root motion 都只能在该 y 上改变 x。

AppKit 使用无边框、非激活、透明 `NSPanel`。窗口位于普通窗口与 Dock 前方，加入所有 Space，并且不能抢占键盘焦点。窗口层级通过真实 macOS 桌面验收，不能只从常量值推断正确。

## 5. 枕头场景

第一版不把枕头建模为独立物理对象。猫与枕头由同一组逐帧画面渲染，但元数据必须区分：

- 猫体点击区域
- 猫与枕头联合可见边界
- 枕头可见区域
- 地面、主体和头部锚点

当前 B 姿势是 `pillow.gateway.leaning.right` 的候选端点。它已经被多个素材路径复用，但成为正式网关前仍需验证短循环和真实桌面接缝。

网关只承担普通场景进出、枕头路径汇合、点击醒来和预加载。枕头内部随机换姿优先使用直接有向边，不应每次让五百先回网关醒来。

`sit.front.pillow` 与普通 `sit.front.floor` 是两个视觉上下文节点。二者都面向用户，但前者必须保留同一枕头，不能通过运行时临时叠加道具伪造。

## 6. 帧渲染与预加载

- PNG/RGBA 序列是制作事实源，首个运行时逐帧寻址。
- 每帧可以有独立时长，播放器不假设全包只有一个 FPS。
- 使用固定最大画布，动作切换时不按 alpha 包围盒调整窗口尺寸。
- 当前 clip、可选出边和目标循环首帧必须在安全退出前完成解析与预加载。
- 解码失败不能降级为硬切、冻结上一帧蒙版或跳到目标第 0 帧。
- 睡眠内部逐帧和终点 root motion 必须严格为零。

## 7. 坐标、道具与 root motion

每个宠物包使用统一运行时画布和坐标。不同母片只允许在编译副本上对整条已批准路径应用一次固定变换，不能逐帧重新居中或修改源帧。

手动拖动偏移与动作 root motion 是两套状态：

```text
windowX(t) = userPlacedX + scale × rootMotionPt.x(t)
windowY(t) = userPlacedY
```

普通睡姿、枕头睡姿、坐姿及其内部过渡 root motion 为零。进入或离开枕头场景时，可以使用已批准的一至两步水平累计 root motion。通用走跑 root motion 继续保留在工程能力中，但睡眠 MVP 行为层不得请求它。

## 8. 素材生成 Skill 与运行时边界

素材 Skill 负责照片输入、provider 适配、任务账本、母片生成、抠图、固定变换、机械报告、人工验收暂停点和包编译。运行时只消费经过验证的数据包。

多次生成不设固定全局次数上限，但每次必须有明确假设变化。结果未知时查询原任务，不自动重投。所有失败候选和批准配方保留，不能因方向调整删除历史。

## 9. 权限、配置与信任边界

- 运行时无账号、会话、服务端、数据库或网络 API。
- 运行时不读取 Seedance、TOS 或其他 provider 凭据。
- 生成凭据只存在于用户本机环境、钥匙串或被忽略配置，不进入包、Git、日志和 AIREADME。
- MVP 不需要辅助功能权限，不安装全局桌面点击监听。
- 宠物包是不受信任输入，必须先验证路径、schema、文件类型和哈希，再允许加载。
- 原始宠物照片、生成母片和真实桌面录屏默认属于私有工作区，不进入公开仓库。

本项目没有邮件、定时服务、公开 SEO 页面、Webhook、内嵌 Agent 或运行时自动化，因此不创建对应的平行文档。素材生成 Skill 是用户主动运行的离线制作流程，不是桌面应用内的自动 Agent。

## 10. 验证现状与缺口

### Existing coverage

2026-08-10 使用完整 Xcode 真实执行 25 项 XCTest，0 失败。

| 已有覆盖 | 当前证据 | 边界 |
|---|---|---|
| 包完整性、hidden、缺失与篡改拒绝 | `PackageLoaderTests` | 只覆盖当前 `0.1.0` 工程包 |
| 图引用、安全退出、过渡完整播放与预加载 | `PackageLoaderTests`、`GraphPhaseTests` | 不覆盖新增场景和节点职责字段 |
| 掉帧直采样、循环相位与速度关系 | `PlaybackTimelineTests` | 速度关系属于保留的工程能力 |
| 睡眠零 root motion 与现有换姿路径 | `PackageLoaderTests`、行为规划测试 | 不代表全部首发睡姿已经接入 |
| 点击目的地、走跑和边界规划 | `EngineeringBehaviorPlannerTests` | 已绿色，但属于首发弃用能力，不应被误读为 MVP 覆盖 |

### Proposed automated tests

| 用例 | 必须固定的规则 | 预期负向结果 |
|---|---|---|
| 加载 `0.2.0` 包 | `behavior.json`、scene、role、props 和命中字段完整解析 | 缺任一必需字段时拒绝 installable 包 |
| 生成自主候选集 | 只包含 `autonomousEligible=true` 的 `dwell` 节点 | 网关或坐姿进入候选集时失败 |
| 场景点击 | floor 与 pillow 分别到对应 sit 节点 | 枕头场景解析到无枕头坐姿时失败 |
| 请求去抖 | 同时最多一个尚未开始的点击目标 | 过渡中点击形成无限队列时失败 |
| 猫体命中 | 枕头与透明画布不触发宠物点击 | 点击枕头导致唤醒时失败 |
| 拖动恢复 | 用户 y 在松手和后续零 root motion 动作中保持 | 动作把宠物吸回底部时失败 |
| 默认输入面 | 不安装全局桌面点击 monitor | MVP 默认启动注册 monitor 时失败 |
| 枕头道具连续 | pillow scene 全路径 props 一致 | 中途缺枕头、变 scene 或错误边界时失败 |

### Manual review gaps

- 30 分钟随机调度是否安静、无固定轮播和高频切换。
- 点击后是否在目标时间内出现自然醒来反应。
- 当前靠枕 B 的短循环和进出接缝是否适合作为正式网关。
- 猫体命中区是否既不会误点枕头，也不会让细尾和耳朵难以点击。
- 窗口是否始终位于普通窗口和 Dock 前方，并在全屏、锁屏与 Space 切换后恢复。
- 枕头场景全部路径的身份、接触、压缩和尺度连续性。

测试绿色不能升级人工视觉状态，也不能证明真实窗口层级和长期陪伴感。

## 11. 禁改项 / Forbidden Refactors

- 不把生成 provider、账号、额度或网络调用放入桌面运行时。
- 不把已搁置的点击目的地移动重新包装成 MVP 默认行为。
- 不用全局鼠标监听替代宠物窗口内点击和拖动。
- 不退化成平面动作 ID、固定时长轮播或随机硬切。
- 不把网关和交互节点加入随机睡姿池。
- 不让枕头在同一场景中无过渡出现、消失或改变尺度。
- 不用整个猫枕联合 alpha 作为宠物点击区域。
- 不用固定速度标量、CSS 内部平移或独立计时器代替逐帧 root motion。
- 不默认镜像正式左右素材。
- 不把动态 WebP 或 MP4 设为唯一运行时事实源。
- 不静默混入失败抠图帧、未批准候选或没有生产履历的素材。
