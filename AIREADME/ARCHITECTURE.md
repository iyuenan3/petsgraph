# ARCHITECTURE：petsgraph

> 本文同时记录目标架构和 Phase 0 原型的 as-built 边界。宠物包精确字段见 `SPEC.md`，决策理由见 `DECISIONS.md`。

## 组件 + 数据流

```text
用户宠物照片与可选视频
  → 素材生成 Skill
  → 用户自行配置的 Seedance 等 provider
  → 连续视频母片
  → 逐帧提取与抠图
  → 画布归一化、root motion 提取、锚点与碰撞标注
  → 机械预筛
  → 单动作人工验收
  → 有向图边人工验收
  → 宠物包编译与完整性校验
  → 本地安装
  → 动作图调度器
  → 帧渲染器 + 原生窗口运动驱动
```

## 当前 as-built 原型

- `PetsGraphCore` 负责宠物包路径安全、图引用、逐帧 root motion、相位旋转、中断策略和完整性校验。片段集合从图引用推导并显式寻址，hidden 必需文件、缺失条目和哈希变化都会拒绝加载。掉帧后直接按单调时间重新采样，不累加历史 delta。
- `PetsGraphApp` 使用透明无边框 AppKit `NSPanel`，主运行循环从 `ProcessInfo.systemUptime` 取同一单调时钟，同时选择 PNG 帧和设置原生窗口 x。
- `build-prototype-package.py` 从已批准私有 PNG 事实源生成 320px 原型帧、锚点、碰撞区、逐帧累计 root motion、图、评审状态和 SHA-256 清单。它在编译前验证批准序列摘要，使用非点号临时目录，并在安装前后拒绝任何 `UF_HIDDEN` 文件标记。
- 当前可以播放包内声明的移动或睡眠演示序列，但还不是完整自主行为调度器。窗口不可拖动，不处理屏幕边缘返向、睡眠恢复或正式安装。
- 走路 30 pt/s 已通过用户窗口速度验收，跑步保持 115 pt/s。睡眠四段 root motion 严格为零，趴卧到侧躺再返回的睡眠子图已通过真实桌面链路验收。
- 合并预览包包含右向移动和睡眠两个已批准子图。由于还没有已批准的站立或坐下到趴卧桥接动作，两者暂时不连通，包明确保持 `installable=false`。
- 全包沿用 640px 源画布、320px 运行时画布与共享源地面 `y=532`。睡眠事实源地面 `y=440`，四段编译副本统一应用固定平移 `(0,+92)`，源帧不变，也不逐帧重新居中。

### 1. 素材生成 Skill

负责输入检查、provider 适配、任务账本、动作母片生成、逐帧后处理、预览、机械报告、人工验收暂停点和宠物包编译。它不提供付费额度，不替用户保存密钥，也不决定桌面行为。

### 2. 包编译器与验证器

把已批准 PNG 序列、动作图和逐帧元数据编译成 `.petsgraph-pet`。它验证图可达性、帧引用、alpha、锚点、root motion、左右方向、验收状态和完整性哈希。分页图集是后续可重建优化，不是制作事实源。

### 3. 安装器

只导入通过严格校验的数据包。安装采用新版本并存或可恢复替换，不在失败时破坏当前可用包。

### 4. 动作图调度器

调度器管理三个不同状态：

- `requestedAction`：行为层请求的目标。
- `renderedAction`：当前稳定播放的循环或有限活动。
- `actionTransition`：等待安全退出、预加载边、播放有向过渡或进入目标节点。

普通流转：

```text
stable/current-loop
  → waiting-for-safe-exit
  → preload-edge-and-target
  → playing-directed-edge
  → entering-target
  → stable/target-loop
```

同一时间只保留一个尚未开始的普通目标，后到请求可以替换旧请求，不能堆积无限过渡队列。过渡一旦开始，普通自主行为不得中途改主意。

### 5. 行为调度层

第一阶段行为调度只负责形成有意图的短序列，而不是直接随机挑动画：

- 空闲时在稳定姿态循环中停留。
- 移动意图先选择方向和目标距离，再由图生成起步、走路、跑步、减速和停步链。
- 玩耍、进食和舔毛使用带冷却的有限活动，结束时回到声明的稳定姿态。
- 屏幕边缘、用户拖动、隐藏、锁屏和系统睡眠属于环境约束或强中断。

### 6. 帧渲染器

- 第一原型逐帧寻址 RGBA PNG，支持每帧独立时长。
- 使用固定最大画布，动作切换时不按可见包围盒重设窗口尺寸，避免窗口边缘抖动。
- 当前帧 alpha 用于精确命中；粗碰撞区域用于屏幕边缘预测。
- 当前片段、所有可选出边和目标首帧必须在切换前预加载，解码不能落在切换关键路径上。

### 7. 原生窗口运动驱动

- 动画帧与窗口位置共享同一个单调时钟和同一个 action start timestamp。
- 每次更新直接采样累计 `rootMotionPt(t)`，不累加帧间 delta。
- 走路、跑步、加速、减速和停步的窗口速度来自素材轨迹，行为层只决定方向和目标，不另造与素材冲突的速度曲线。
- 第一阶段只更新窗口 x，y 固定在当前显示器底部安全活动带。
- 接近边缘时根据当前片段剩余 root motion、可用安全退出帧和停止片段制动距离提前请求减速，不能撞到边缘后瞬间反向。
- 窗口运动循环必须在原生侧或等价的低延迟层执行。不得让高频跨进程 IPC 成为逐帧同步前提。

## 关键技术选型

- macOS 单平台优先，跨平台契约与运行时实现解耦，见 ADR-001。
- 直接生成视频的连续帧是动作来源，见 ADR-002。
- 姿态与方向组成图节点，循环和有向过渡组成边，见 ADR-003。
- PNG 序列是制作事实源，图集是后续运行时编译物，见 ADR-004。
- 累计 root motion 与帧共享时钟并驱动原生窗口，见 ADR-005。
- 正式左右素材独立生成，见 ADR-006。
- 素材 Skill 与离线运行时通过数据包隔离，见 ADR-007。
- 动作、边和整链分层人工验收，见 ADR-008。

首个 root motion 原型采用 Swift/AppKit，原因见 ADR-012。该选择只锁定 Phase 0 证据路径，不代表正式运行时技术栈已经永久锁定；通过同步稳定性、透明窗口行为、内存和维护成本验收后再决定是否继续，不以参考项目技术栈直接继承。

## 强中断语义

- 拖动宠物：立即停止普通动作链，清除待执行目标，用户松手后从当前位置恢复到兼容稳定姿态。
- 隐藏、锁屏、系统睡眠：暂停并隐藏；恢复时不续播过渡中间帧，回到稳定姿态。
- 退出应用：可以立即终止进程，不要求为了视觉完整性延迟退出。
- 即将越界：不是强制瞬移，应提前进入已批准的减速和停步路径。

## 禁改项 / Forbidden Refactors

- 不把生成 provider、账号、额度或网络调用放进桌面运行时。
- 不退化成平面动作 ID 列表、固定时长随机切换或每次从目标第 0 帧硬切。
- 不用 CSS 内部平移冒充桌面窗口移动。
- 不用单一 `speed` 字段替代逐帧 root motion。
- 不默认镜像正式左右素材。
- 不把动态 WebP 或 MP4 设为唯一运行时事实源。
- 不静默复用失败抠图帧、混入未批准候选或用机械检查自动升级验收状态。
- 不在首条真实上桌动作链通过前批量生成完整动作包。
