# RELATIONS：petsgraph

## 出向依赖（我用了谁）

当前没有运行时项目依赖。PetsGraph 安静陪伴运行时离线工作，不依赖账号、服务端、数据库、分析平台或网络 API。当前正式内嵌宠物是李五百。飞流的 11 节点、20 条有向边和精抠素材整链已在私有制作侧人工通过，仍未编译为运行时包。宠物身份由各自宠物包提供。

| 依赖 | 用途 | 边界 |
|---|---|---|
| Seedance 视频生成服务 | 生成连续动作母片与有向过渡 | 只属于私有定制制作侧，不进入桌面运行时；凭据不写入仓库、文档或宠物包 |
| Seedream 与 `gpt-image-2` 静态图片服务 | 生成或编辑身份基准、姿态锚点、安全画布参考和严格端点图 | 不作为正式动作视频来源，不把静态图批准自动升级为动作批准；本机配置只通过被 Git 忽略的环境变量提供 |
| 本地逐帧抠图与包编译工具 | 抠图、归一化、命中区、root motion、校验与打包 | 作为内部生产工具复用，输出数据包，不向运行时暴露生成实现，也不承诺跨宠物零人工适配 |

## 只读参考项目

- `mochi-master` 只读参考快照：参考透明桌面窗口、内容寻址素材、生成服务适配和逐帧抠图。它不是代码依赖，petsgraph 不继承其平面动作表、固定时长切换或动态 WebP 唯一运行时路线。
- `petsdesk` 前任项目：只用于复盘窗口交互、真实窗口位移、素材验收和失败路线。petsgraph 不复用其九宠产品边界、持续活跃调度、随机行为评分或速度标量动画契约。

## 入向（谁用我）

- 当前 PetsGraph Swift/AppKit 桌面运行时消费通过完整性校验的 `.petsgraph-pet`，五百 `0.4.0` 已达到 `runtime-chain-approved` 并以固定裁剪 RGBA 作为默认包内嵌。`0.3.1` PNG 包继续作为制作事实源和公开回滚基线。
- 喜欢五百的朋友通过 GitHub Release 下载 Apple 芯片 DMG，把 App 安装到自己的 Mac。GitHub 是发布载体，不是运行时依赖。
- Maxwell 的私有定制制作流程产出符合 `SPEC.md` 的素材包。朋友如需自己的宠物，由 Maxwell 单独评估照片、习惯、姿态和道具后受托制作，不开放自助生成入口。
- 当前没有其他项目把 petsgraph 作为依赖。
