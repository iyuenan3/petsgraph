# ROADMAP：petsgraph

## Now（低功耗运行时候选）

PetsGraph 通用 App 与李五百默认宠物包已经分层，`0.3.1` 状态为 `runtime-chain-approved` 和 `installable=true`。当前焦点是让朋友从 GitHub Release 成功安装，并保护已经通过的素材基线。

1. 发布 `v0.3.1` DMG、备用 App ZIP、睡姿总览和校验和，并让 GitHub Actions 核验精确附件集合后发布草稿。
2. 收集朋友在 Apple 芯片、macOS 14 及以上环境的首次安装反馈，记录 Gatekeeper、启动和菜单可理解性问题。
3. 收集真实整日与连续数天使用感受，观察随机长尾、普通与枕头场景占比、近期去重和内存表现。
4. 保持默认物理屏幕左下角、中文指定睡姿、宠物本体点击、全桌面拖动、Dock 前方层级和离线运行边界。
5. 维护私有批准注册表、生成账本和失败候选。正式运行时媒体进入 Release，原始照片、生成任务和拒绝候选继续私有。
6. 冻结 `e80fa09` 的固定 clip 裁剪预乘 RGBA 候选，完成全部普通与枕头睡姿、点击往返、拖动、锁屏恢复和长时间资源占用的人工视觉回归。
7. 保留 v0.3.1 PNG Release 作为当前正式回滚基线。低功耗候选在人工通过前保持 `installable=false`，不覆盖同名包或附件。

## 已搁置（+原因）

- 点击桌面目的地后走路或跑步：与首个产品价值无关，并引入全局点击监听、方向、边界和响应状态复杂度。
- 自主巡游：会持续抢夺注意力，破坏安静陪伴。
- 玩耍、进食、复杂互动和命令面板：没有证明比高质量睡眠更能提高留存陪伴感。
- 多宠互动：关系、碰撞、遮挡和素材规模会同时扩大，偏离单宠质量主线。
- Intel Mac 与通用二进制：首批朋友的目标设备是 Apple 芯片，先减少发布矩阵和未验证环境。
- 云账号、同步、市场和付费代生成：用户自行配置 provider，项目不承接额度和私密素材托管。
- 骨骼、肢体拼接、Hatch Pet、RIFE、光流和自动补间作为主路线：机械连续不等于真实宠物动作自然。
- 动态 WebP 作为唯一运行时格式：不能保证精确逐帧寻址、安全退出、点击区域和 root motion 同步。
