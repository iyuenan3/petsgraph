## 已搁置（+原因）

- 点击坐立和指定动作：与“观察而非指挥”的纪念边界冲突，也扩大连续视频连接数量。
- 窗口跟随步行和桌面巡游：引入 root motion、边界、方向和窗口跳动风险，却不增加核心陪伴价值。
- 多宠互动：每个包只描述一只宠物；跨包关系会扩大素材、同步和验收状态空间。
- 骨骼、精灵图、RIFE、光流和自动补间：机械流畅不能替代真实身份、承重和连续视频生命感。
- 通用一键生成：历史照片与视频质量不一，身份、习惯、场景和可接受动作必须逐宠判断。
- 云账号、订阅授权、素材市场和强 DRM：客户应长期离线拥有 `.petpack`，Player 不依赖持续运营的服务端。
- 当前阶段同时实现 iPadOS、电视端、Intel Mac、Windows on Arm、32 位 Windows 或 Linux：先收敛 Apple Silicon macOS 与 Windows x64 的共同契约和生命感。
