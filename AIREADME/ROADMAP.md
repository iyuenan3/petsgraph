# ROADMAP：petsgraph

## Now（稳定本地 `0.2.0`）

李五百睡觉陪伴 MVP 已完成，状态为 `runtime-chain-approved` 和 `installable=true`。当前焦点是保护这条已通过基线，不为了展示能力恢复走跑默认行为。

1. 保持正式包与获批 preview.10 帧哈希一致，任何素材或动作图变化使用新版本并重新验收。
2. 收集真实整日与连续数天使用感受，观察随机长尾、普通与枕头场景占比、近期去重和内存表现。
3. 保持默认物理屏幕左下角、宠物本体点击、全桌面拖动、Dock 前方层级和离线运行边界。
4. 维护私有批准注册表、生成账本和失败候选，公开仓库只提交代码、契约和脱敏方法。

## Next

4. 根据长期观察决定是否加入低频伸懒腰、舔毛或轻微注视。任何新增动作都必须服务陪伴感，不能为了展示能力而加入。

## 已搁置（+原因）

- 点击桌面目的地后走路或跑步：与首个产品价值无关，并引入全局点击监听、方向、边界和响应状态复杂度。
- 自主巡游：会持续抢夺注意力，破坏安静陪伴。
- 玩耍、进食、复杂互动和命令面板：没有证明比高质量睡眠更能提高留存陪伴感。
- 多宠互动：关系、碰撞、遮挡和素材规模会同时扩大，偏离单宠质量主线。
- 云账号、同步、市场和付费代生成：用户自行配置 provider，项目不承接额度和私密素材托管。
- 骨骼、肢体拼接、Hatch Pet、RIFE、光流和自动补间作为主路线：机械连续不等于真实宠物动作自然。
- 动态 WebP 作为唯一运行时格式：不能保证精确逐帧寻址、安全退出、点击区域和 root motion 同步。
