# CORE：petsgraph

## 身份

PetsGraph 是面向真实宠物的 macOS 单宠桌面陪伴运行时与素材包体系。App、宠物身份和行为配置相互分离，首发内置宠物是李五百。第一款体验仍是安静睡眠陪伴，核心不是功能数量，而是熟悉的宠物长时间自然待在桌面上。

## 使命

让用户在工作时获得自己真实宠物的安静陪伴。宠物必须保持可辨认的身份、自然的承重和连续的动作关系，而不是一组随机切换的通用视频贴纸。

长期仍计划把已验证的照片、生成、抠图、验收和打包流程抽象成 Skill，让用户自行配置生成服务，为自己的宠物制作本地素材包。

## 当前交付边界

- macOS 单宠、单个本地素材包、离线运行时。
- 默认睡眠，随机时间切换普通睡姿和枕头睡姿。
- 点击宠物在睡眠与正面坐姿之间切换。
- 菜单栏可以用中文名称指定 10 种睡姿。当前不可中断动作播放完成后再执行最后一次选择。
- 用户可以在整个桌面范围拖动宠物，宠物始终位于普通窗口和 Dock 前方。
- 睡眠内部 root motion 严格为零。只有进入或离开枕头场景的已批准短步动作可以产生水平 root motion。
- App 名称固定为 `PetsGraph`，菜单从宠物包读取当前宠物名称。首发只交付李五百，并通过 GitHub Release 向喜欢五百的朋友公开。
- 通用素材生成 Skill 在五百公开版稳定后验证。

## Non-Goals（明确不做）

- 首个 MVP 不开放点击桌面目的地移动，不自主巡游，不把走路或跑步作为默认行为。
- 首个 MVP 不做玩耍、进食、舔毛、养成数值、任务提醒或 Agent 能力。
- 第一阶段不做多宠、宠物关系、宠物碰撞、Intel Mac、Windows、Linux 或跨显示器移动。
- 不做云账号、素材市场、付费代生成、托管额度或运行时联网生成。
- 不监听宠物之外的全桌面鼠标点击，不以辅助功能权限作为 MVP 前提。
- 不把骨骼建模、Hatch Pet、肢体拼接、RIFE、光流、交叉淡化或自动补帧作为正式素材路线。
- 不以动态 WebP 作为未经验证的唯一运行时格式。

已完成的走路、跑步和 root motion 素材不删除、不降级，也不混入首个 MVP 的默认行为。它们作为后续可选活动能力继续保留。

## 绝不 / Hard Constraints

- 真实宠物身份、动作质量和陪伴感优先于动作数量、互动数量与生成次数。
- 正式动作来自直接生成视频的连续原始帧。确定性后处理可以抠图、统一画布、固定重定位和编译，但不得伪造承重或补造动作。
- 生成可以在用户明确授权下进行多次受控尝试。每次都必须有新的失败假设或约束变化，完整保留任务、输入、提示词、seed、结果与拒绝原因；禁止无差别批量抽卡。
- 素材身份、动作自然度、接触关系、透明边缘和切换质量最终由人工视觉验收。机械检查只能预筛。
- 运行时只能沿动作图切换。普通行为等待安全退出，预加载下一条边和目标循环，有向过渡按原帧顺序完整播放。
- 睡姿随机调度只能选择允许长期停留的节点。网关、交互节点和过渡边不能被当作普通睡姿随机抽取。
- 枕头是核心场景的一部分。进入枕头场景后，枕头的位置、尺度、方向和接触关系必须连续；点击、坐起和拖动不能让枕头突然消失。
- 点击只作用于宠物本体。枕头和透明画布不应扩大点击命中区域。
- 用户拖动属于强操控，可以在全桌面改变 x 和 y。自主动画和场景进出最多只改变 x，不能偷偷改写用户放置的 y。
- 独立动作通过不等于可安装。动作、图边、完整场景链和真实桌面长时间运行必须分别验收。
- 宠物包只包含数据与媒体，不执行包内脚本，不携带生成凭据、原始私密照片、签名 URL 或 provider 配置。
- PNG/RGBA 序列是制作事实源；图集是可重建运行时产物；WebP、GIF 和 MP4 只用于预览或导出。
- 低功耗运行时副本只能从已批准 PNG 包确定性编译。每条 clip 只允许一个固定裁剪矩形，不能逐帧重新定位、缩放或修改批准源帧。

## 生命周期

`public-alpha / petsgraph-0.3.1 + wubai-quiet-companion-0.3.1`。通用 App 统一使用 `PetsGraph` 和 `com.maxwell.petsgraph`，当前内置李五百。普通睡眠、枕头睡眠、两个场景坐姿、点击往返、随机换姿、中文指定睡姿、全桌面拖动、窗口层级、左下角默认位置和异常恢复已经组成完整离线运行时。

正式包状态为 `runtime-chain-approved` 和 `installable=true`。获批链包含 53 个 clip、14 个节点与 39 条边，已通过 45 项 XCTest、6,925 条完整性记录、30 分钟真实桌面稳定性观察、正常速度与慢放评审，以及拖动、Space 和锁屏恢复人工验收。`0.3.0` 的全部获批帧与 `0.2.0` 哈希一致。

公开版只构建 Apple 芯片 `arm64`，最低 macOS 14。App 使用 ad-hoc 签名，没有 Developer ID 签名和 Apple 公证，朋友首次打开时需要通过 Finder 右键「打开」或「隐私与安全性」确认。正式媒体内嵌在 App 中，Release 不再重复上传独立 `.petsgraph-pet`。

main 分支提交 `e80fa09` 新增 schema `0.4.0` 的固定 clip 裁剪预乘 RGBA 候选、内存映射播放、有界预加载和单实例锁。它保留 `0.3.1` PNG 包作为不可变事实源，完整候选为 53 个 clip、6,866 帧和 1.827 GB。57 项 XCTest、完整性校验、全部媒体帧可读和真实桌面随机换姿链已通过；普通睡眠约 1.3% 到 1.6% CPU、53 MiB，连续过渡约 2.1% 到 2.7% CPU、19 到 46 MiB。该候选仍为 `cropped-rgba-awaiting-human-runtime-review` 与 `installable=false`，未替换已发布的 v0.3.1。
