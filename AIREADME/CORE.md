# CORE：petsgraph

## 身份

PetsGraph 是为 Maxwell 自己和朋友们熟悉的真实猫狗制作的 macOS 单宠桌面陪伴项目。App、宠物身份和行为配置相互分离，首发内置宠物是李五百，当前下一只定制宠物是飞流。第一款体验仍是安静睡眠陪伴，核心不是功能数量，而是熟悉的宠物长时间自然待在桌面上。

## 使命

让 Maxwell 和朋友们在工作时获得熟悉宠物的安静陪伴。每只宠物都必须保持可辨认的身份、自然的承重和连续的动作关系，而不是被套进同一组通用姿势的视频贴纸。

生产工具会继续复用照片管理、provider 调用、抠图、验收、履历和打包能力，但不再承诺把它们做成面向所有用户的一键通用素材生成 Skill。新增宠物采用人工定制：先研究该宠物真实习惯，再为它单独设计姿态、道具、动作图和行为参数。

## 当前交付边界

- macOS 单宠、单个本地素材包、离线运行时。
- 默认睡眠，在每只宠物自己的合法动作图上按随机长尾时间换姿，不做固定串行轮播或随机硬切。
- 点击宠物在当前视觉场景的睡眠与正面坐姿之间切换。带道具场景必须有保留同一道具的专用坐姿。
- 菜单栏可以用中文名称指定当前宠物包声明的睡姿。当前不可中断动作播放完成后再执行最后一次选择。
- 用户可以在整个桌面范围拖动宠物，宠物始终位于普通窗口和 Dock 前方。
- 睡眠内部 root motion 严格为零。只有进入或离开枕头、猫窝等道具场景的已批准短步动作可以产生水平 root motion。
- App 名称固定为 `PetsGraph`，菜单从宠物包读取当前宠物名称。首发只交付李五百，并通过 GitHub Release 向喜欢五百的朋友公开。
- 飞流采用无道具与猫窝两个场景，当前动作图为 5 个无道具睡姿、4 个猫窝睡姿和 2 个点击坐姿。`rest.floor.prone.right` 是地面枢纽，连接地面正面坐姿、侧身伸展睡、紧蜷睡、半仰睡和猫窝蜷睡；仰躺睡只经半仰睡往返。`rest.cat-bed.curled` 是猫窝枢纽，连接猫窝正面坐姿、猫窝自然趴睡、猫窝侧伸睡和猫窝舒展露腹睡。两个坐姿不进入自主睡姿随机池，收爪趴睡与睡眠香箱不进入当前图。
- 新宠物只按 Maxwell 自有宠物或朋友明确委托的定制项目推进，不以姿势数量、动作图或道具的跨宠物一致为目标。

## Non-Goals（明确不做）

- 首个 MVP 不开放点击桌面目的地移动，不自主巡游，不把走路或跑步作为默认行为。
- 首个 MVP 不做玩耍、进食、舔毛、养成数值、任务提醒或 Agent 能力。
- 第一阶段不做多宠、宠物关系、宠物碰撞、Intel Mac、Windows、Linux 或跨显示器移动。
- 不做云账号、素材市场、付费代生成、托管额度或运行时联网生成。
- 不做任意用户上传照片后自动产出完整宠物包的通用自助产品，也不以一套固定十姿势模板约束所有宠物。
- 不监听宠物之外的全桌面鼠标点击，不以辅助功能权限作为 MVP 前提。
- 不把骨骼建模、Hatch Pet、肢体拼接、RIFE、光流、交叉淡化或自动补帧作为正式素材路线。
- 不以动态 WebP 作为未经验证的唯一运行时格式。

已完成的走路、跑步和 root motion 素材不删除、不降级，也不混入首个 MVP 的默认行为。它们作为后续可选活动能力继续保留。

## 绝不 / Hard Constraints

- 真实宠物身份、动作质量和陪伴感优先于动作数量、互动数量与生成次数。
- 正式动作来自直接生成视频的连续原始帧。确定性后处理可以抠图、统一画布、固定重定位和编译，但不得伪造承重或补造动作。
- 生成可以在用户明确授权下进行多次受控尝试。每次都必须有新的失败假设或约束变化，完整保留任务、输入、提示词、seed、结果与拒绝原因；禁止无差别批量抽卡。
- 素材身份、动作自然度、接触关系、透明边缘和切换质量最终由人工视觉验收。机械检查只能预筛。
- 运行时只能沿动作图切换。普通行为等待安全退出，预加载下一条边和目标循环，有向过渡按原帧顺序完整播放。
- 睡姿随机调度只能选择允许长期停留的节点，并受场景粘性、近期去重、节点权重和活动冷却约束。网关、交互节点和过渡边不能被当作普通睡姿随机抽取。
- 枕头是核心场景的一部分。进入枕头场景后，枕头的位置、尺度、方向和接触关系必须连续；点击、坐起和拖动不能让枕头突然消失。
- 猫窝是飞流核心场景的一部分。猫和猫窝作为同一组已批准画面播放；同一条过渡路径只能使用一个固定空间变换，不能逐帧重新定位或在运行时临时拼接猫窝。
- 点击只作用于宠物本体。枕头和透明画布不应扩大点击命中区域。
- 用户拖动属于强操控，可以在全桌面改变 x 和 y。自主动画和场景进出最多只改变 x，不能偷偷改写用户放置的 y。
- 独立动作通过不等于可安装。动作、图边、完整场景链和真实桌面长时间运行必须分别验收。
- 宠物包只包含数据与媒体，不执行包内脚本，不携带生成凭据、原始私密照片、签名 URL 或 provider 配置。
- provider 只属于私有制作侧。Seedance 负责连续动作视频，静态身份图、姿态锚点和安全画布参考可使用 Seedream 或 `gpt-image-2`；任何 provider 都不能直接绕过人工验收进入正式宠物包。
- PNG/RGBA 序列是制作事实源；图集是可重建运行时产物；WebP、GIF 和 MP4 只用于预览或导出。
- 低功耗运行时副本只能从已批准 PNG 包确定性编译。每条 clip 只允许一个固定裁剪矩形，不能逐帧重新定位、缩放或修改批准源帧。
- 粗抠阶段一旦完成人工通过的整段缩放与平移，精抠只能改变透明度和边缘颜色，不能重新拟合位置或尺度。已经干净的素材保持逐字节不变，只选择性重做确有毛边或主体保护问题的片段。

## 生命周期

`public-alpha / petsgraph-0.4.0 + wubai-quiet-companion-0.4.0`。通用 App 统一使用 `PetsGraph` 和 `com.maxwell.petsgraph`，当前内置李五百。普通睡眠、枕头睡眠、两个场景坐姿、点击往返、随机换姿、中文指定睡姿、全桌面拖动、窗口层级、左下角默认位置和异常恢复已经组成完整离线运行时。

正式 v0.4.0 包状态为 `runtime-chain-approved` 和 `installable=true`。获批链包含 53 个 clip、14 个节点与 39 条边，运行时媒体包含 6,866 帧和 113 条完整性记录。57 项 XCTest、完整包与媒体校验、本机普通睡眠和连续换姿资源测量已经通过。既有 30 分钟真实桌面稳定性、正常速度与慢放、点击、拖动、Space 和锁屏恢复结论来自同一批准动作图的 v0.3.1 PNG 基线。

公开版只构建 Apple 芯片 `arm64`，最低 macOS 14。App 使用 ad-hoc 签名，没有 Developer ID 签名和 Apple 公证，朋友首次打开时需要通过 Finder 右键「打开」或「隐私与安全性」确认。正式媒体内嵌在 App 中，Release 不再重复上传独立 `.petsgraph-pet`。

v0.4.0 从 v0.3.1 的已批准 PNG 包确定性编译 schema `0.4.0` 固定 clip 裁剪预乘 RGBA，保留 PNG 包作为不可变制作事实源和回滚基线。解压后媒体约 1.827 GB，无损压缩 DMG 约 548 MiB。普通睡眠约 1.3% 到 1.6% CPU、53 MiB，连续过渡约 2.1% 到 2.7% CPU、19 到 46 MiB。GUI 使用每用户单实例锁，重复启动在加载媒体前退出。

飞流素材侧当前达到 `human-approved-selective-fine-matte-graph-tour`：11 个节点、20 条有向边、31 个唯一素材。12 条地面素材完成选择性精抠，另外 19 条已干净素材逐字节复用；固定整段变换、帧序和批准速度均未改变。该结论只覆盖素材动作图和精抠整链，飞流运行时包、真实桌面随机游走和 `installable=true` 尚未批准。
